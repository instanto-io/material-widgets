# Material showcase

The catalogue uses the original views, UiBinder templates, examples and descriptions
from [gmd-core-demo](https://github.com/GwtMaterialDesign/gmd-core-demo/tree/63528c811e5e91a6bdbd5b523748d47251cc89f9).
Its sidebar and page header follow the upstream showcase layout.

[Open the TeaVM showcase](https://instanto-io.github.io/material-widgets/)
or compare it with [upstream](https://gwtmaterialdesign.github.io/gmd-core-demo/).
Upstream comparisons belong in this guide; the live catalogue demonstrates TeaVM examples.
Pages can be bookmarked, and the catalogue supports search and browser history.

Use **Dark mode** in the toolbar to switch between light and dark colours. Your
choice is remembered on this browser, including when opening full-page navigation
demos. Light mode is the default. Fonts and layout stay the same in both modes.

For local commands, see [building locally](BUILDING.md). For the scope of the
browser checks, see [port status](COMPATIBILITY.md). The separate
[design document](DESIGN.md) explains how the original views run without GWTP
or Gin and records source and asset changes.

The text-field page retains the upstream template, including its hidden Contacts
autocomplete example. Browser tests reveal that control temporarily to check the
original contact oracle and chip selection; the published page keeps upstream’s
visibility setting.

The Errors page retains the original email validator and status-message handlers.
Its Clear buttons remove error and success messages and restore any configured
helper text, matching upstream behaviour. Combo Box keeps its helper description
separate from its error/success label.

## Table examples

These are the original [Material Table showcase](https://github.com/GwtMaterialDesign/gmd-table-demo)
views and templates running on TeaVM. The option panels below each table retain
the original handlers. Data is generated locally, including the infinite table's
asynchronous fixture service. No database or application server is required.

| TeaVM example | What to try | Upstream comparison |
|---|---|---|
| [Standard](https://instanto-io.github.io/material-widgets/#!table-standard) | Sort columns, select rows, change density and inspect the event log. Use the square toolbar icon to expand the table to the viewport, then press it again to restore the layout. The upstream **Add Row** control replaces the dataset with one row; **Add All Rows** restores 50. | [Standard](https://gwtmaterialdesign.github.io/gmd-table-demo/#!standard) |
| [Paged](https://instanto-io.github.io/material-widgets/#!table-paged) | Step through 52 local users with the buttons or focus them and press Enter; change rows per page and hide or restore columns from the toolbar. | [Paged](https://gwtmaterialdesign.github.io/gmd-table-demo/#!paged) |
| [Categorised](https://instanto-io.github.io/material-widgets/#!table-categorized) | Open and close product groups, inspect category totals and computed columns. | [Categorised](https://gwtmaterialdesign.github.io/gmd-table-demo/#!categorized) |
| [Frozen](https://instanto-io.github.io/material-widgets/#!table-frozen) | Explore the original fixed-column layout and horizontal scrolling. | [Frozen](https://gwtmaterialdesign.github.io/gmd-table-demo/#!frozen) |
| [Customised](https://instanto-io.github.io/material-widgets/#!table-customized) | Inspect custom table styling, rendering and column configuration. | [Customised](https://gwtmaterialdesign.github.io/gmd-table-demo/#!customized) |
| [Infinite](https://instanto-io.github.io/material-widgets/#!table-infinite) | Scroll through an asynchronously loaded window over 125 local users. | [Infinite](https://gwtmaterialdesign.github.io/gmd-table-demo/#!infinite) |

The [table design note](TABLE-DESIGN.md) explains how the original views are
launched and where compatibility changes live. See [port status](COMPATIBILITY.md)
for the distinction between rendered examples and tested interactions.

stages of the port.
