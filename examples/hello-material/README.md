# Hello Material

This standalone TeaVM application shows a Material text box, button and
greeting label. [HelloMaterial.java](src/main/java/io/instanto/material/example/HelloMaterial.java)
initialises the original widget API, then attaches the form through
`RootPanel`. The [host page](src/site/index.html) loads the styles and
JavaScript required by the widgets.

Copy this example to begin your own application. Keep the complete
`gwt-material/` asset folder beside the host page so fonts and icons load.
For template-based views, follow the
[UiBinder processor guide](https://github.com/instanto-io/teavm-compat/tree/main/gwt-uibinder-processor).
